## Сопоставление с установкой старого скрипта

- Старый install.ps1 скачивает готовый run.exe по закреплённому URL и проверяет хеш. Новый форк пока не опубликован, поэтому его автономный installer включает исходники и собирает Windows exe на машине пользователя.
- Оба сценария устанавливают Ollama при отсутствии, загружают qwen3.5:9b и выполняют пробную генерацию.
- Новый installer использует NSIS, отдельный каталог и ярлык приложения. Это Electron с внутренними runtime-файлами, а не Python single-file exe; для пользователя точка входа — один .ps1.
- Существующее хранилище Ollama не перемещается, OLLAMA_MODELS не меняется. Старый скрипт имел отдельное требование про Desktop/ollama_models — в первоначальном запросе нового форка его нет.
- Старый rollback.ps1 не переносился: он привязан к другому продукту и общим моделям. Удаление нового приложения выполняется его NSIS-деинсталлятором; автоматически удалять общую Ollama/модель нельзя. Это отличие явно сохранено, а не объявлено реализованным откатом по PLAN.md.

## Что делает единый installer

1. Проверяет Windows x64 и отсутствие работающего CopilotSelection.
2. Распаковывает встроенные исходники в LOCALAPPDATA/CopilotSelection-setup/build-… .
3. Загружает Node 24.22.1 в эту папку, сверяет SHA-256 с официальным SHASUMS256.txt. Адрес checksum проверен, HTTP 200.
4. При необходимости ставит Python 3.12 через winget, устанавливает npm/Python зависимости.
5. Проверяет TypeScript, запускает Vitest, собирает helper и NSIS; проверяет handshake helper.
6. При необходимости ставит Ollama через winget; ждёт API, выполняет pull и пробный generate.
7. Устанавливает NSIS, инициализирует провайдер только для свежего профиля, запускает приложение. Первый экран выбора режима остаётся доступен.

Нужны интернет, рабочий winget/App Installer, разрешение на установку пакетов и достаточно места для модели и сборки. При ошибке остаются журнал и рабочая папка; установка не выдаёт сообщение об успехе после ненулевого exit code. Это не транзакционный откат зависимостей: Python/Ollama, поставленные до последующей ошибки, остаются установленными.
