# Реализация Copilot Selection

Дата: 30.10.2026. База: `c1ac1177180135c628f2c6b344f82578832d89e7`.
Локальная ветка: `feat/selection-input`.

## Реализовано

- Основной режим чистой установки — выделение + одиночный Ctrl; голосовой режим выбирается отдельно.
- Текстовая сессия без вызова `asr.ensure()` и запуска захвата звука, один ответ `say` вместо пары say/points.
- Отдельный редактируемый промпт, модель/провайдер, температура, think, таймаут подключения и общий срок запроса.
- Native Ollama `/api/generate` для выделения; голосовой chat-путь сохранён. Модели получаются через `/api/tags`. Автоматический fallback для выделений отключён.
- Windows helper: release-based hotkeys, UIA → проверенный Ctrl+C, проверка foreground HWND, отказ от прежнего clipboard и защищённых UIA-полей.
- JSON Lines по stdio, UTF-8, handshake, лимит сообщений, epoch отмены, завершение helper при выходе.
- Настраиваемые send/settings/toggle/quit. Одиночный Escape скрывает, двойной отменяет; toggle отменяет работу, quit доступен и при отключённых остальных клавишах.
- Экран текстового режима: ручной вопрос, полный редактируемый ответ, копирование, повторный показ, развёрнутый ответ и отмена.
- Ограничение компактного ответа не обрезает полный текст.
- Отдельные appId, userData, имя exe и установщика, без переноса данных исходного Copilot.
- Просмотр и применение импорта Ollama Overlay: параметры Ollama и поддерживаемые клавиши; неперенесённые поля перечисляются. Исходный файл не меняется.
- Миграция старых настроек Copilot сохраняет голосовой режим и существующие сочетания, создаёт backup. Повреждённая/будущая схема не заменяется.
- Windows helper build script, упаковка через extraResources, Windows job CI и обновлённый release workflow.

## Запуск на Windows x64

Нужны Node 24 и Python 3.12 для сборки. Пользователю готовой сборки Python/Node не нужны. Ollama с моделью устанавливается отдельно.

```powershell
npm ci
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-selection-helper.ps1
npm run dev
```

Для установщика после сборки helper:

```powershell
npm run dist
```

Выбрать «Выделенный текст + Ctrl» при первом запуске, настроить провайдер Ollama и модель либо роль «Быстрый ответ». Адрес стандартного Ollama preset: `http://127.0.0.1:11434/v1`. Выделения используют native API того же сервера.

Дополнительные настройки: «Настройки → Ввод». Главная страница текстового режима показывает полный ответ. Ctrl+Alt+S открывает раздел ввода. Для чистой установки снимок области перенесён на Ctrl+Alt+P. Если старые назначения конфликтуют, предупреждение доступно во вкладке ввода.

## Проверки и границы подтверждения

На Linux пройдены TypeScript typecheck, production bundle, 106 тестов Vitest и 4 теста Python распознавателя клавиш. Vitest запускался с разрешённым локальным HTTP-сервером: sandbox запрещал listen на 127.0.0.1.

Windows helper синтаксически скомпилирован, но сборка Windows EXE, установка и фактическое чтение выделения/clipboard на Windows в этой сессии не выполнены. Windows job добавлен в CI, но ещё не запускался на GitHub. До релиза нужно выполнить ручную матрицу из PLAN.md на целевой машине. Успешные Linux-проверки не подтверждают работу Windows hooks.

GitHub-форк не опубликован: в среде нет gh и подключённого инструмента создания репозиториев. `origin` пока указывает на upstream; push в него не выполнялся. Для публикации создать fork в своём аккаунте и назначить его как origin, текущий origin переименовать в upstream.

## Оставшиеся задачи перед выпуском

- Выполнить Windows build и smoke test на чистой машине, проверить UIA/clipboard в конкретных программах, отмену и отсутствие кражи фокуса.
- Подтвердить завершение упакованного helper при выходе/аварии и работу смены устройств/масштабирования.
- Проверить UI вручную и пройти голосовую регрессию на Windows.
- Импорт внешнего вида намеренно не преобразует несовместимые Win32/Tk координаты в Electron; они перечисляются как неперенесённые. Старый плоский overlay_settings.json с одним внешним видом даёт только такой отчёт.
- Helper не перезапускается автоматически после падения: показывает ошибку, повторный запуск доступен переключением voice → selection. Hybrid остаётся будущим этапом.
- Пользовательские значения send/settings/toggle/quit требуют проверки на Windows; формат имён — как у Python keyboard (ctrl+alt+s).

`projects/script` и его установленная версия при реализации не изменялись.

## Обновление после аудита

См. [AUDIT.md](AUDIT.md). Добавлен автономный `release/install.ps1`; запуск:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
```

Один файл включает исходники текущей версии. Сборка происходит на целевой Windows: Node загружается в рабочую папку, Python/Ollama устанавливаются при необходимости. Автоматически загружается и проверяется qwen3.5:9b. Настройки существующей установки сохраняются. Перед повторной установкой закрыть приложение. Старое хранилище моделей и `OLLAMA_MODELS` не меняются. Сборка может занять заметное время и требует интернета и свободного диска.

Для регенерации файла после изменений: `python scripts/make-standalone-installer.py`. Команды `npm run dist` и `npm run dist:dir` теперь сами собирают helper. PowerShell-синтаксис проверен парсером 7.5.4, но это не Windows end-to-end проверка.
